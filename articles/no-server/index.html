個人情報の名簿、ネットにコピペして大丈夫？｜サーバーに送信しないツールの見分け方

2026.10.17　さくらツールズ

「データをサーバーに送信しません」
ツールの説明でこの一文を見かけても、何がどう安心なのか、ピンとこない人は多いはずです。

サーバーって何？
データを送信するのとしないのとで、何が違う？
インターネットだから個人情報だめだよね？
このツール大丈夫？

データをサーバーに送信しませんだけでは、安心することはできませんよね。

最近便利なWebツールがたくさんあります。
その中には、個人情報の入力を促すツールも少なくありません。

会社なら、社員の名簿やお客さまの名前。
学校なら、子どもの名前や成績。

勝手に公開してはいけない個人情報をコピペと言われても・・・
「規則に違反するかもしれない」と思うと、手が止まってしまう方が多いのが現状ではないでしょうか。

実は
「データをサーバーに送信しません」
そう書いてあるツールなら、入力した名簿があなたのパソコンやスマホから流出することはありません。
Webツールの作成者や運営者にも、ほかの人にも見られることはありません。
もちろん、AIの学習に使われることもありません。
だから、安心して利用できるのです。

この記事でわかること

  • サーバーの意味
  • 送信する・送信しないの違い
  • 送信しないツールを使うときに気をつけること

この記事では、銀行と財布のたとえで、わかりやすく解説します。

安心してWebツールを使うために、理解を深めていきましょう。
そして、このサイトにある「さくらツールズ」のツールを使い倒してください！

サーバーとは？

サーバーは、インターネットの向こう側にあるコンピューターです。
運営する会社の建物やデータセンターに置かれ、たくさんの人のデータを預かっています。

たとえば、GoogleドライブやLINE、メールの中身。
どれも、自分のスマホの中だけでなく、運営する会社のサーバーに保存されています。
だから、スマホを買いかえても、パソコンから開いても、同じデータが出てきます。

総務省は、こうした仕組み（クラウドサービス）について、データは事業者のサーバーに保管され、インターネットを通じてやりとりされると説明しています。
インターネットがつながっていればどこからでも開ける便利さは、データが「向こう側」、つまり事業者の手元にあるからこそ成り立っています。

「送信する」と「送信しない」の違い

データを「送信する」「送信しない」の違いは、お金にたとえると分かりやすくなります。

  • サーバーに送信する＝銀行に預ける。どこのATMからでも引き出せる。そのかわり、お金は自分の手を離れ、銀行が管理する
  • サーバーに送信しない＝財布に入れておく。財布の外には出ない。そのかわり、財布を家に忘れたら、出先では使えない

サーバーに送信すると、事業者がそのデータを管理します。
サーバーに送信しなければ、自分のパソコンの中でデータを管理します。

サーバーに送信していない名簿は、保存しているパソコンが必要です。
だから、会社や自宅で名簿を保存しているパソコンで操作をする必要がありますよね。
財布の考え方と一緒です。

送信するサービスの見分け方

では、お金の場合、財布のお金が無くなったらどうしますか？
通常、銀行でお金を引き出す場合、キャッシュカードと暗証番号が要ります。
ネットバンキングでも、IDとパスワードでログインしないと、自分の口座は開けません。

サーバーも同じです。
GoogleドライブやLINEのように、データを預けて、あとで自分のものとして取り出すサービスには、IDとパスワードの登録が欠かせません。
たくさんの人のデータが集まる場所で、「これはあなたのデータ」だとサーバーが見分けるための鍵だからです。

反対に、送信しないツールには、データを預ける先がありません。
だから、IDもパスワードも不要です。
「登録なしで使える」と書いてあれば、送信しないツールだと見分けるひとつの目印になります。

この違いが理解できれば、自分が使いたいツールがどちらなのかを見分けられ、安心して使えるようになります。

送信しないツールの中で起きていること

「送信しない」ツールでも、Webツールだからページを開くときはインターネットを使います。
そこで不安を感じる人がいるかもしれません。

Webページの仕組みは、ページを開けただけで勝手に送受信するようになっていません。
開けたときに自分のパソコンで起こっているのは、その「ページの画面」と「動かすための仕組み」が届けられているだけです。

だから、Webツールで、Excelから名簿をコピーして貼り付けをしても大丈夫と言えるのです。

例えば、教室の座席表で、名簿をコピペしたとします。
ボタンを押すと座席が自動で貼り付けられて席を並べかえてくれますが、その処理はすべて自分の端末の中だけで行われています。

インターネット上のページに入力するのだから、ボタンを押した瞬間にどこかに送られるのでは。そう不安に感じて、使えずにいた人もいたでしょう。

でも、ボタンを押しても、入力した中身が運営者のサーバーへ送信されることはありません。
ツールが、そもそも名簿を外へ送る作りになっていないからです。
ツールの運営者の側には、だれが何を入力したかの記録が残る仕組みもありません。
運営者の手元に届かない名簿は、AIの学習に使われることもありません。

ここで疑問がわいてきませんか？

それなら、自分のパソコンで入力したデータは、どうなってるの？
どこにあるの？どうして表示されるの？

それでは保存先を確認しましょう。

Webツールで使うデータの保存先

「保存」ボタンがあるWebツールの保存先は、自分が使っているブラウザの中の保存場所になります。

ブラウザとは、ホームページを見るためのアプリのことです。
パソコンならGoogle ChromeやMicrosoft Edge、iPhoneならSafariが代表的なブラウザです。

ブラウザには、ページごとに小さな保存場所が用意されていて、Webツールはその仕組みを使っています。
保存した内容は、ブラウザを閉じても残すことが可能です。
だから、保存したときと同じ端末の、同じブラウザの、同じユーザーで開けば、データを呼び出すことができるのです。

送信しないツールのよいところ

ここからが本題です。
送信しないツールのいちばんのよさは、名簿が外に出ないことです。

  • 運営者にも見えない：サーバーに届かないので、運営者が見ることはできません
  • 漏れる場所がない：運営者のサーバーに名簿がないため、サーバーが狙われても名簿は漏れません
  • AIの学習に使われない：運営者の手元に名簿が届かないので、学習に使いようがありません
  • 登録がいらない：預ける先がないので、IDやパスワードを作る必要がありません

サーバーに送信するサービスでは、人のミスで中身が見えてしまうことがあります。
身近な例として、GoogleドライブやOneDriveのようなクラウドサービスを考えてみましょう。
共有の設定をまちがえると、見せるつもりのない相手にまで、中身が公開されてしまいます。
サーバーに送信しないツールなら、名簿は端末の外に出ません。共有の設定ミスで名簿が見えてしまう心配もないのです。

送信しないツールの注意ポイント

財布に入れたお金は、財布ごとなくせば戻りませんよね。

送信しないツールも同じで、守ってくれるのは自分の端末だけです。
自分の端末を壊したり無くしたりすると、その保存したデータは使えなくなります。

別の端末からは開けない

会社や職員室のパソコンで保存した名簿は、自宅のパソコンやスマホには出てきません。
同じパソコンでも、ChromeとEdgeのようにブラウザが違えば、別の保存場所になります。
同じChromeでも、ユーザー（プロフィール）を切り替えると、別の保存場所です。
続きを別の端末でしたいときは、ファイルやPDFに書き出して持ち運びましょう。

消えたら戻せない

ブラウザの「閲覧データの削除」で、保存した内容は消えます。
シークレットモード（プライベートブラウズ）で開いた場合も、ウィンドウを閉じた時点で消えます。
運営者のサーバーに控えがないので、運営者に頼んでも戻せません。
大事な名簿は、元のExcelなどを手元に残しておきましょう。

共有のパソコンでは消して帰る

みんなで使うパソコンで保存すると、次に使う人が同じブラウザの同じユーザーで、同じツールを開いたときに、名簿が出てきます。
共有の端末で使ったときは、使い終わったら保存を消してから離れてください。

さくらツールズの名簿の使い方

さくらツールズで入力した名簿や座席の配置は、お使いの端末の中だけで処理しています。
サーバーに送信することはありません。
席替えなどの計算も、AIに名簿を渡して行うものではなく、端末の中で決まった手順で計算しています。
ここでは、座席表を例に、名簿の入れ方・保存・呼び出し・削除を順に紹介します。

名簿は、Excelから貼り付けると楽

名簿は、1人ずつ手で入力してもかまいません。
でも、Excelに名簿があるなら、名前の列をコピーして、「エクセルから貼り付ける」の欄に貼りつけましょう。
項目名（見出しの行）は要りません。

座席表など、座る位置を決めるツールは、ドラッグで簡単に移動できるようにしています。
コピペしたあとにボタンで自動設定してくれますが、マグネットのように手で足したり直したりできるから本当に使い勝手が良いのが特徴です。

保存は、ブラウザの中だけ

会社の名簿やクラスの名簿は、年単位で利用し何度も作り直したいことがありますよね。
その場合、いちいち同じ名簿のコピペをするのはストレスです。
だから保存できる仕組みを作りました。

保存の方法は2つ。

  • データに名前を付けて保存：名前を付けて、20件まで残せます。クラスや部署ごとに分けて残したいときに使います
  • この画面を保存する：いま開いている画面を、そのまま1つだけ残します。名簿を入れかえると、前のものは上書きされます

どちらも、残るのは使っている端末のブラウザの中だけ。
もちろんどこにも送信されないので安心です。

保存した名簿の呼び出し

次に使うときは、①名簿の入力にある「保存済のデータ」から名簿を選び、「このデータを自動入力」を押します。
名簿も条件も入るので、あとは席替えするだけです。
名前を付けて保存した名簿は、さくらツールズのほかの道具でも呼び出せます。

名簿を共通して使えるのは、次の6つです。

  • 教室の席替えメーカー
  • 席次表
  • バスの座席表
  • 新幹線の座席表
  • ランダム指名
  • 簡単スライド

転入・転出で変わった名簿は上書き

保存した名簿は、あとから直せるようにしています。
名簿を呼び出して、1行足したり消したりしたら、「上書き」を押してください。
転入・転出で人が入れかわったときや、異動で部署のメンバーが変わったときに使えます。
新しい名簿を一から貼り付け直す必要はありません。

見積書メーカーと請求書メーカーで共通

経理ツールの見積書メーカーと請求書メーカーも、入力したものは使っている端末のブラウザの中だけで処理しています。
保存の分類を4つにして使いやすくしています。

  1. 自分の情報（名前・住所・振込先など）
  2. 取引先
  3. 詳細のひな形
  4. 備考

これらは2つで共通して使えます。

また、見積書メーカーで保存した取引先は、請求書メーカーでもそのまま呼び出せる仕組みにしています。

要するに、見積りをして請け負ったら、そのままの形で請求書を発行できるということです。
仕事の時短になりますね。

作った見積書・請求書そのものは残らないので、ボタン一つで作成できる控えを必ずPDFで保存してください。

いらなくなった名簿の削除

保存した名簿は、「保存済のデータ」で選んで「削除」を押すと簡単に削除できます。
「この画面を保存する」のチェックを外すと、画面の保存も消えます。
共有のパソコンで使ったときは、ここで消してから離れましょう。

アクセス解析と広告について

さくらツールズでは、ページの見られ方を知るためのアクセス解析（Googleアナリティクス）と、広告を使っています。集めるのはページの見られ方だけで、入力した名簿は含まれません。くわしくはプライバシーポリシーをご覧ください。

まとめ

サーバーに送信しないとは、入力した中身が、あなたの端末の外へ出ないということです。
運営者にも見えず、漏れる場所もなく、AIの学習にも使われない。
そのかわり、別の端末では開けず、消えたら戻せません。

名簿のように人に見られたくないものは、送信しないツールで。
ただし、元のデータは必ず手元に残しておく。
この2つを守れば、安心して名簿を使えます。

まずは座席表で、Excelからの名簿の貼り付けと保存を試してみてください。
