```
（サーバー＝sakura-tools 直下を 8766 で配る）
chrome --headless=new --disable-gpu --hide-scrollbars --user-data-dir=（一時フォルダ）
       --window-size=1280,720 --virtual-time-budget=（待つミリ秒） --screenshot=出力.png
```
