## 4. 撮り方（1280×720・16:9）

⭐**本物のアプリの画面で設定をやり直して、そこから中身を取り出す。**自分で組み立てない。

1. ブラウザで道具を開き、**上の表のとおりに設定して「作る」を押す**
2. `#sheet` の中の `.grid` の中身を取り出す
3. **同じCSSを読む1枚のHTML**を作って、ヘッドレスChromeで撮る
   ```
   chrome --headless=new --disable-gpu --hide-scrollbars
          --window-size=1280,720 --screenshot=出力.png  file:///…/xxx_shot.html
   ```

### ⚠画像にするときだけ足すもの（画面のCSSには入れない）
- ⭐**外枠・角丸・影を消して、1280×720にいっぱいに置く**
- ⭐**空席の「空」の字を消す／白にする**（画面には出るが、画像には出さない）
- 行の高さを決め打ちする（座席表 86px／席次表 104px）＝画面の高さに引きずられないように
- ⚠**`sample` クラスを外す**（付けると SAMPLE の透かしが出る）
- 右下に「さくらツール　sakura-tools.com」（`sheet-credit`）
