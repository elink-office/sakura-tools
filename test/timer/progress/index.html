進行タイマー

セミナーや司会で、残りの時間を色の帯で見る

  • 発表者や司会者用に、時間の帯だけを小さく表示できるから、進行しやすい
  • 原稿を見ながらでも、目の端に入る色で残りが分かる
  • 午前・午後など、プログラムを複数組んでおけて、当日も臨機応変に対応できる
残り 90分

帯は小さいウィンドウに出ています。

データに名前を付けて保存0/20⁠

🔒 保存先もインターネットではありません。使っている端末のブラウザの中だけに残るので、ほかの人からは見えません。パソコン・タブレット・スマホ、どれでも同じです。

  • 1日の研修なら「午前」「午後A」「午後B」のように、休憩までのひとまとまりごとに名前を付けて保存しておけます。当日は「保存済のデータ」から選ぶだけです。
  • 休憩が延びて始まりが遅れたときは、「今から」を押してください。終わりの時刻はそのままで、帯が合わせて縮みます。
  • 「上書き」は、選んでいるデータを今の設定に置きかえます。保存できるのは20件までです。
  • 同じパソコンでも、別のブラウザ（ChromeとEdgeなど）には出ません。

🔒 保存したものは、使っている端末の中だけに残ります。

時間の設定

〜％ 〜％ 〜終わりまで 過ぎたとき

ウィンドウを小さくすると、帯だけになります。パソコンの画面の端に置いて使えます。

こんなときに使う

  • 90分の授業
    前回の復習 → 説明 → 課題、の流れなら、色の区切りを授業に合わせておけます。
    たとえば「青＝復習と説明」「緑＝課題」「黄＝まとめ」。
    説明が長引いても、帯を見れば課題の時間を削っていることにすぐ気づいて、ペースを戻せます。
  • 発表会・会議の司会
    発表者が4人で、1人10分、40分で終わらせたいとき。
    「1ブロック」を10分にすれば、1ブロックが発表者1人分になります。
    今は何人目の時間か、押しているかが、ブロックの位置で分かります。
  • 1日のセミナー・研修
    午前・午後A・午後Bを、休憩までで区切って保存しておきます。
    休憩が延びても「今から」を押せば、終わりの時刻はそのままで帯が縮みます。
    押した分は、次の休憩で調整できます。
  • 自分の発表
    パワーポイントの発表者ツールの上に、帯だけを小さく出しておけます。
    原稿や聞いている人を見ながらでも、目の端の色で残りが分かります。
