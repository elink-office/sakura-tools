⑦ PDFで保存

保存するときに出てくる名前です。日付・取引先・金額の3つが入っていると、あとから探せます。

⑧ 保存したデータの利用

保存した取引先とひな形は、さくらツール内の請求書・見積書・領収書で使えます。

🔒 保存したものは、使っている端末の中だけに残ります。

🔒 保存先もインターネットではありません。使っている端末のブラウザの中だけに残るので、 ほかの人からは見えません。パソコン・タブレット・スマホ、どれでも同じです。

  • ⚠作った見積書そのものは残りません。控えはPDFで保存してください。
  • 取引先は、名前を付けて20件まで保存できます。名前は会社名（氏名）がそのまま付きます。
  • 呼び出すのは②の「この取引先を自動入力」から。会社名も担当者も住所も入ります。
  • ひな形は、③の中の件名と④見積の内容です。取引先とは別に、名前を付けて30件まで残せます。
  • 自分の情報は1件だけです。押すたびに上書きします。
自分の情報をこの端末に保存

①の内容をロゴも含めて保存します。

①の中の屋号・氏名・住所・電話・メール・ロゴと、⑤の中の備考をまとめて残します。

1件だけなので、押すたびに上書きします。ロゴの画像も残ります。

取引先データに名前を付けて保存（0／20件）

②の中の会社名・敬称・担当者・住所を20件まで残します。⭐請求書メーカーと共通です。

⚠③の中の件名や④見積の内容は、この下の「見積の内容をひな形として保存」で保存します。

名前は、②の中に入れた会社名・氏名がそのまま付きます。「上書き」は、担当者が変わったときに使ってください。保存できるのは文字情報のみです。

⭐請求書メーカーと共通です。請求書で保存した取引先も、見積書メーカーでそのまま呼び出せます。

呼び出しは、保存した後に②に出る「この取引先を自動入力」からできます。

見積の内容をひな形として保存（0／30件）

③の中の件名と④見積の内容を30件保存できます。そのため同じ取引先で2つ以上のひな形を保存できます。

⭐請求書メーカーと共通です

⭐次も同じ内容を出すときに使います。名前は「株式会社もみじ　案1」のように、自分で分かる形で付けてください。空のままなら、②の中の取引先と③の中の件名をつないで、自動で付きます。

請求書メーカーと共通です。請求書で保存したひな形も、見積書メーカーでそのまま呼び出せます。

⚠出した書類の控えではありません。控えはPDFで保存してください。ひな形は「次も使う内容」を残す場所です。

呼び出しは、保存した後に③に出る「このひな形を入れる」からできます。

⚠作った見積書は必ずPDFで保存してください。この端末には保存されません。

使い方
  1. ①に自分の情報を入れて、⑧で「保存」を押します。次からは入りません。
  2. ②に取引先を入れます。一度保存すると、次からは選ぶだけです。
  3. ③で番号と件名を決めます。エクセルの表があれば、③の中の「エクセルから貼り付ける」に貼れます。
  4. ④に品目と金額を入れます。消費税と合計は自動で出ます。
  5. ⑤に有効期限と備考を書きます。ここも保存できます。
  6. ⑥で紙の見た目を確かめます。
  7. ⑦のPDFで保存を押して、出てきた画面で「PDF」を選びます。
  8. 見積が通ったら、⑦のこの内容で請求書を作るで請求書メーカーに移ります。

できること

  • 見積書番号の自動採番　頭は自由に決められて、末尾が1つずつ増えます
  • 端数の選択　切り捨て・切り上げ・四捨五入から選べます
  • 空の行　途中に入れた空の行は、そのまま紙にも出ます
  • インボイスの欄　登録番号がある方だけ、①のチェックで出せます
  • ひな形　件名と④の内容に名前を付けて残せます。同じ取引先で2つ以上持てます
  • エクセルからの貼り付け　1行目に見出しがあれば、並び順がちがっても振り分けます
  • 請求書への引きつぎ　見積が通ったら、中身をそのまま請求書メーカーへ移せます

こんなときに

  • 副業や個人事業で、はじめて見積書を出すとき
  • 同じ取引先に、いつも同じ内容で見積もるとき
  • エクセルの表を毎回コピーして作り直しているとき
  • 作った見積書がどこにあるか分からなくなるとき

ネットにつながっているのに、外に出ないのですか
ページを開くときだけ通信します。入力した内容は送っていません。作る処理は、すべて使っている端末の中で動いています。
入力した内容は、どこかに送られますか
送られません。AIの学習に使われることもありません。
会社の決まりでクラウドが使えません
お使いいただけます。登録もインストールもいりません。データを預かる仕組みがないためです。
作った見積書は、あとから開けますか
開けません。このツールは見積書を保存しません。控えはPDFとして、使っている端末に保存してください。取引先・ひな形・自分の情報は保存しているので、同じ内容ならすぐ作り直せます。
見積書番号は自分で決められますか
決められます。③の「番号の頭」に好きな文字を入れると、末尾の番号だけが1つずつ増えます。番号そのものを書き直すこともできます。一度使った番号を入れると、赤字でお知らせします。
この見積書から、請求書は作れますか
作れます。⑦の「この内容で請求書を作る」を押すと、取引先と④の中身がそのまま請求書メーカーに入ります。⚠見積書の控えは残らないので、先にPDFで保存してください。
同じ取引先に、2つの案を出したいのですが
できます。⑧の「見積の内容をひな形として保存」で、「〇〇株式会社　案1」「案2」のように名前を付けて残せます。③から呼び出せます。
PDFのファイル名は変えられますか
保存するときに書き直せます。⑦のチェックで、入れる項目を選ぶこともできます。
消費税の端数は、切り捨てと切り上げのどちらが正しいですか
どちらでも構いません。決まりはなく、同じ取引先にはいつも同じものを使うほうが、あとで差額が出ません。
インボイスの登録番号がありません
①のチェックを入れなければ、登録番号の欄は出ません。登録していない方は、そのままお使いください。
データの扱い

入力した内容は、すべて使っている端末の中だけで完結します。外部には送っていないので、個人情報が漏れることも、AIの学習に使われることもありません。登録もインストールもいりません。すべて無料です。

保存するもの

  • 自分の情報（屋号・氏名・住所・電話・メール・登録番号）
  • 取引先の一覧
  • ひな形（件名と、見積の内容）
  • 備考
  • 番号の形と、最後に使った見積書番号

保存しないもの

  • 作った見積書そのもの（品目・数量・金額）
  • 作りかけの下書き
  • 過去に出した見積書の一覧

気をつけること

  • ⚠共用の端末で使ったときは、⑧の「保存したデータを全部消す」を押してから閉じてください
  • ⚠ブラウザの履歴を消すと、保存したものも一緒に消えます
  • ⚠控えはPDFです。このツールは保存の場所ではありません
