⑥ PDFで保存

印刷画面で「PDF」を選ぶと、そのまま保存できます。紙に印刷することもできます。

保存するときに出てくる名前です。日付・取引先・金額の3つが入っていると、あとから探せます。

保存される名前　請求書.pdf

⑦ 保存したデータの利用

保存した取引先は、請求書・領収書・見積書で使えます。

🔒 保存したものは、使っている端末の中だけに残ります。

🔒 保存先もインターネットではありません。使っている端末のブラウザの中だけに残るので、 ほかの人からは見えません。パソコン・タブレット・スマホ、どれでも同じです。

  • 取引先は、名前を付けていくつも保存できます。名前は会社名（氏名）がそのまま付きます。
  • 呼び出すのは②の「この取引先を自動入力」から。会社名も担当者も住所も入ります。
  • 自分の情報は1件だけです。押すたびに上書きになります。
  • 同じ名前で保存したときは差し替えるか聞きます。同じものが2件できることはありません。
  • ⚠作った請求書そのものは残りません。控えはPDFで保存してください。

取引先データに名前を付けて保存（0／20件）

②の会社名・敬称・担当者・住所をまとめて残します。名前は会社名がそのまま付きます。

「上書き」は、担当者が変わったときに使ってください。保存できるのは文字情報のみです。

呼び出すのは②の「この取引先を自動入力」から。

自分の情報をこの端末に保存

①の内容をロゴも含めて保存します。

①の屋号・氏名・住所・電話・メール・ロゴと、④のお振込先・備考をまとめて残します。

1件だけなので、押すたびに上書きになります。ロゴの画像も残ります。

⚠作った請求書は必ずPDFで保存してください。この端末には保存されません。

使い方
  1. ①に自分の情報を入れて「覚える」を押します。次からは入りません。
  2. ②に請求先を入れます。一度覚えると、次からは選ぶだけです。
  3. ③に品目と金額を入れます。消費税と合計は自動で出ます。
  4. ④に振込先を書きます。ここも覚えます。
  5. ⑥の印刷を押して、出てきた画面で「PDF」を選びます。

できること

  • 請求書番号の自動採番　頭は自由に決められて、末尾が1つずつ増えます
  • 端数の選択　切り捨て・切り上げ・四捨五入から選べます
  • 空の行　途中に入れた空の行は、そのまま紙にも出ます
  • インボイスの欄　登録番号がある方だけ、①のチェックで出せます

こんなときに

  • 副業や個人事業で、はじめて請求書を出すとき
  • 毎月、同じ取引先に同じ内容を請求するとき
  • エクセルの表を毎回コピーして作り直しているとき
  • 作った請求書がどこにあるか分からなくなるとき

データの扱い

入力した内容は、すべて使っている端末の中だけで完結します。外部には送っていないので、個人情報が漏れることも、AIの学習に使われることもありません。登録もインストールもいりません。すべて無料です。

保存するもの

  • 自分の情報（屋号・氏名・住所・電話・メール・登録番号）

  • お振込先と備考
  • 番号の形と、最後に使った請求書番号

保存しないもの

  • 作りかけの下書き
  • 過去に出した請求書の一覧
